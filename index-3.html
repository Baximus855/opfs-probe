OPFS Fill-Swap-Fill Contention Test v2

Same fill-swap-fill load as index-2.html, with one addition: stats are logged per block as the test runs, not only as a final pooled summary. This is the only way to tell a stable effect apart from one that builds up over the course of a long run (heat, accumulating wear-levelling pressure, etc). Note the device temperature yourself at the start, roughly the midpoint, and the end, there is no reliable way to read it from the page.

Requires frost_probe.bin to already exist. If you have just restarted, run the timing probe (index.html) first to recreate it, or this test will report a clear error instead of crashing. This test creates and deletes frost_swap.bin repeatedly during LOAD blocks. Per-block stats appear as each block finishes, do not wait for the very end to start reading. Tap Run.
