OPFS Fill-Swap-Fill Contention Test

Heavier load pattern: repeatedly allocate and discard a large file instead of steady random reads/writes against one fixed file. Stresses filesystem allocation and deallocation, not just data throughput. Reuses the existing measure file (frost_probe.bin), same idle/load structure as the original contention test, for direct comparison.

Requires frost_probe.bin to already exist. If you have just restarted, run the timing probe (index.html) first to recreate it, or this test will report a clear error instead of crashing. This test creates and deletes frost_swap.bin repeatedly during LOAD blocks. Tap Run.
